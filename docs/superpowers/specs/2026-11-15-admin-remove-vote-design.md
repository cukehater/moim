# 운영자 투표 삭제 (기명 모임) 설계

## 의도
투표자는 쿠키(voter token)로만 구분해서 다른 브라우저·시크릿 창으로 중복 투표할 수 있다. 운영자가 상세 화면에서 중복이 의심되는 투표자 한 명의 투표를 통째로 지울 수 있게 한다.

## 목표 / 비목표
- 목표: 기명 모임에서 운영자가 특정 투표자의 투표(선택 전체)를 삭제
- 비목표: 익명 모임(누가 누군지 판단할 근거가 없음), 날짜 하나만 빼기, 삭제 되살리기

## 접근 방식
- A. 상세 화면에 투표자 목록 섹션 추가: 사람 단위로 한눈에 보이지만 화면이 길어짐
- B. 결과 표 날짜 줄의 투표자 아바타 → 시트에서 삭제 (**선택**): 화면이 늘지 않음. 한 사람이 고른 날짜가 안 보이는 약점은 시트 줄에 그 사람의 선택 날짜 전체를 보여 보완
- 날짜 단위 선택 제거: 중복 투표는 사람 단위로 지우는 게 맞아 제외

## 화면 (운영자 상세 → 날짜별 결과)
- 기명 모임이면 결과 표 날짜 줄 오른쪽에 투표자 아바타 + › (투표 페이지 VotersSheet와 같은 모양)
- 누르면 시트: 그 날짜 투표자 목록. 줄마다 이름 · 투표 시각 · 그 사람이 고른 날짜 전체 · [삭제]
- [삭제] → 확인 창: "{이름}님의 투표를 지울까요? {날짜들} 선택이 모두 지워지고 되돌릴 수 없어요."
  마감된 모임이면 "확정 날짜가 바뀔 수 있어요" 추가
- 삭제 후 결과·자동 확정은 득표에서 다시 계산됨 (resolveConfirmation이 매번 계산)

## 구현 (빌더 판단 포함)
- `features/vote-remove`: 서버 액션 `removeVote(meetingId, voteId)`
  - `requireAdmin()` → 모임 존재·기명 여부 확인 → `votes`에서 `id`와 `meetingId`가 모두 일치하는 행만 삭제 (vote_selections는 cascade) → `revalidateMeeting`
  - 마감 전후 모두 허용
- 운영자 전용 쿼리(entities/vote): 투표 id, 이름, 투표 시각, 고른 옵션 id들. 공개 쿼리 `getTallies`는 그대로 두어 투표 id를 투표 페이지에 노출하지 않음
- 시트는 `widgets/meeting-result-table` 안에, 아바타는 `shared/ui/voter-chip`의 `VoterAvatar` 재사용
- 확인 창은 `shared/ui/alert-dialog` (모임 삭제와 같은 패턴)
