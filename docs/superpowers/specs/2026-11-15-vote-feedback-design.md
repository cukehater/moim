# 투표 피드백 개선 설계

## 왜
- 운영자가 상세 화면에서 투표 페이지로 바로 갈 길이 없다.
- 투표 성공 안내가 하단 토스트 한 줄이라 약하다.
- 이미 투표한 사람이 다시 들어오면 투표가 됐는지, 고칠 수 있는지 알 수 없다.

## 결정
- 상세 화면 `링크 복사` 옆에 `투표 페이지 열기`(같은 탭)를 둔다. 대시보드 목록에는 넣지 않는다.
- 투표·수정 성공 시 토스트 대신 컨페티와 팝오버를 띄운다. 팝오버에는 고른 날짜가 들어간다. 실패는 기존처럼 토스트로 알린다.
- 투표 중인 모임에 다시 들어오면 "{이름}님은 이미 투표했어요" 모달을 페이지당 한 번 띄운다. 익명 모임은 "이미 투표했어요"로 띄운다. 마감된 모임은 확정 안내 모달과 겹치므로 띄우지 않는다.

## 방식
- 컨페티: `canvas-confetti`를 성공 시점에 dynamic import한다. `disableForReducedMotion`을 켠다.
  - 버린 대안: CSS만으로 만드는 방식. 코드가 늘고 효과가 단조롭다.
- 전체 톤을 파티 쪽으로 바꾸는 리디자인은 별도 작업으로 진행한다.
